# CleanSweep — справка пользователя

Портабельный деинсталлятор и клинер для Windows. Один exe, установки
не требует; настройки (`CleanSweep.ini`) и журнал (`CleanSweep.log`)
хранятся рядом с программой.

> Программа запрашивает права администратора — они нужны для чтения
> HKLM, служб и чужих профилей. Без них часть функций недоступна.

---

## 1. Главное окно — деинсталлятор

Список установленных программ собирается из реестра (64-бит и 32-бит
ветки, все пользователи). Поддерживается поиск по имени, фильтр
«Системные» (показать/скрыть системные компоненты), сортировка по
колонкам.

### Деинсталляция программы

1. Выберите программу → «Деинсталлировать» (или двойной клик → кнопка
   в карточке).
2. Запускается штатный деинсталлятор программы — для MSI, Inno Setup,
   NSIS, InstallShield автоматически подставляются «тихие» флаги.
3. После завершения автоматически ищутся **остатки**: файлы, папки,
   ветки реестра, службы, задачи, ярлыки, автозагрузка.
4. Открывается диалог ревью — удаляется только то, что вы отметили.

### Диалог остатков

Каждый элемент имеет оценку уверенности:

- **зелёный (безопасный)** — точно хвост, отмечен;
- **оранжевый (умеренный)** — вероятно хвост, отмечен;
- **красный (рискованный)** — не отмечен и **не удаляется**, даже если
  отметить вручную;
- **серый (инфо)** — справочно, не удаляется.

> ⚠️ **Папка с живым `.exe` — всегда красная.** Если в найденной папке
> лежит запускаемый exe (не `unins000.exe`-заглушка), это, скорее всего,
> живая копия программы, а не остатки. Такие элементы только для
> просмотра.

Файлы удаляются в корзину, реестр — напрямую (с проверкой защищённых
веток).

### «Найти остатки (без удаления)…»

Правый клик по программе → «Найти остатки (без удаления)…» прогоняет тот
же скан остатков, **не запуская деинсталлятор и ничего не удаляя** —
удобно посмотреть, что останется, до удаления.

Глубина скана — **Меню → «Глубина поиска остатков»**:

- **Быстрый** — основные места (Program Files, AppData, ProgramData,
  ярлыки, ключи программы, автозагрузка);
- **Стандартный** — + TEMP, вложенные ветки реестра, COM, службы,
  MUICache, UserAssist, задачи;
- **Глубокий** — + Prefetch и правила фаервола.

Это настройка, а не действие: выбранная глубина применяется и при
поиске после деинсталляции, и при скан-превью.

## 2. Клинер (меню «Очистка»)

Двухфазная схема: **Анализ → ревью → Очистка**. Ничего не удаляется без
предпросмотра.

### Вкладки и источники

- **«Очистка»** — обычные записи: кэши, журналы, временные файлы.
- **«Пароли и сессии»** — записи про логины, куки, сессии, креденшелы.
  Всегда стартует **пустой**; отметить что-то здесь можно только
  осознанно (с подтверждением) — случайно потерять пароли не получится.

Источники баз (панель сверху): **Custom** (ваши правила), **CCleaner**,
**Default**, **Winapp3**, **Winapp2**. Default и Winapp3 взаимоисключают
друг друга — они пересекаются. Совпадающие записи берутся из первого
по списку источника. Кнопки «Обновить» скачивают свежие базы с GitHub.

**Default.ini — несгораемая стандартная база.** Её заводская копия
вшита в программу: если `data\Default.ini` удалён, он автоматически
восстанавливается при загрузке баз. Файл можно править вручную;
кнопка **«Сбросить»** рядом с Default.ini возвращает заводское
содержимое (спросит подтверждение — правки будут утеряны).

### Работа со списком

- Чекбокс — запись войдёт в анализ. Серые записи — программа не
  установлена (про них знает база, но на машине их нет).
- Оранжевое имя + `(!)` — у записи есть предупреждение в базе (текст —
  в статусной строке при выделении).
- Выделение строк: Ctrl/Shift — несколько записей (для «В Custom» и
  контекстного меню). Отметка чекбоксов и выделение — независимы.
- **«Пресеты…»** — выбор по осям «назначение × безопасность»
  (например: только Windows-кэши безопасных записей).
- **«Анализ»** → список того, что будет удалено (файлы, ключи реестра,
  размер). **«Проверить…»** — просмотр плана без очистки.
  **«Очистить»** — удаление выбранного.

Отметки вкладки «Очистка» и последний пресет запоминаются между
запусками. Ручные галочки не сбрасываются при перезагрузке баз и
закрытии «Правил…».

### Куки («Куки…»)

Cookie-базы браузеров (Chromium, Firefox) чистятся **точечно внутри
SQLite**, файлом не удаляются. В менеджере кук — список найденных
доменов: отметьте те, чьи логины хотите оставить (keep-list), остальные
можно удалить кнопкой «Удалить не выбранные». Импорт/экспорт списка —
txt-файлом.

### «Закрыть приложения»

Перед очисткой может появиться список запущенных программ, которые
могут держать чистимые файлы (браузеры держат свои базы открытыми).
Цвета строк:

- **чёрные** — обычные приложения, отмечены;
- **синие** — системные процессы, безопасные для закрытия, отмечены;
- **красные** — критические процессы Windows, **не отмечены**. Если вы
  всё же отметите красную строку, программа предупредит о возможном
  сбое системы и попросит подтверждение.

«Закрыть выбранные» — закрывает отмеченные (параллельно, с прогрессом
«Закрыто N из M»); «Не закрывать» — чистка идёт дальше, залоченные
файлы просто будут пропущены.

> Перед самой очисткой программа **завершает оболочку Windows**
> (explorer.exe — пропадают панель задач и рабочий стол), а после
> завершения **восстанавливает сессию через `userinit.exe`** —
> оболочка поднимается так же, как при входе в систему. Это снимает
> блокировки, которые держит проводник, — не пугайтесь чёрному
> экрану, всё вернётся само.

### Специальная очистка

Записи `[Recycle Bin *]` и `[Desktop Dead Shortcuts *]` (в базе Default):
первая опустошает корзину, вторая удаляет ярлыки рабочего стола, чьи
цели физически отсутствуют. В анализе корзина видна отдельной строкой.

## 3. Свои правила (кнопка «Правила…»)

`Custom\*.ini` рядом с exe — ваши записи в том же winapp2-формате, что и
базы. Файл с расширением `.ini.disabled` — выключен.

Менеджер «Свои правила»:

- **«Новая запись…» / «Изменить…»** — визуальный редактор: имя,
  категория, FileKey/RegKey/ExcludeKey, детекция. Кнопка
  **«Проверить…»** прогоняет настоящий анализ — видно ровно то, что
  попадёт в план.
- **«Справка»** — синтаксис (`docs\custom-rules.md`).
- В поставке — два прокомментированных примера: кэш обновлений Windows
  и журналы/дампы Windows. Откройте их через «Изменить…», чтобы увидеть
  заполненную форму.

**«В Custom»** (кнопка и ПКМ → «Копировать в Custom»): выделенные
записи базы копируются в `Custom\<имя>.ini` — можно изучить, как устроено
правило, и улучшить. Копия переопределяет оригинал, базы не меняются.

Полный синтаксис: `docs\custom-rules.md`.

## 4. AppX (верхнее меню)

Удаление UWP/MSIX-пакетов Windows 10/11 по базе `Winappx.ini`
(«фирменный» мусор: игры, промо-приложения). Показываются только
реально установленные у вас пакеты. Отметьте → «Удалить выбранные»
(выполняется `Remove-AppxPackage` через PowerShell).

## 5. Сеть (верхнее меню)

Классический набор сетевого ремонта — «пропал интернет», косяки
DNS/прокси, глюки после VPN-ов и антивирусов. Чек-лист операций:

| Операция | Что делает | Отметка |
|---|---|---|
| Очистка кэша DNS | `ipconfig /flushdns` | безопасна |
| Очистка кэша NetBIOS | `nbtstat -R` + `-RR` | безопасна |
| Очистка ARP-кэша | `arp -d` + `netsh` | безопасна |
| Очистка BranchCache | `netsh branchcache flush` | безопасна |
| Сброс прокси WinHTTP | `netsh winhttp reset proxy` | безопасна |
| Сброс TCP-глобалов | `netsh int tcp reset` | безопасна |
| Сброс Winsock | `netsh winsock reset` | ⚠ребут |
| Сброс стека TCP/IP | `netsh int ip reset` (+ipv6) | ⚠ребут |
| Таблица маршрутизации | `route -f` | ⚠сеть упадёт |
| Обновление IP | `ipconfig /release` + `/renew` | ⚠сеть упадёт |
| Рестарт адаптеров | `Restart-NetAdapter` | ⚠сеть упадёт |

- Колонка **«Последствия»** подкрашивает серьёзность: «прерывает
  связь» — кирпичный, «перезагрузка» — янтарь, «нужен админ» —
  стальной, «безопасно» — зелёный. Названия операций не окрашены.
- Кнопки «Отметить всё» / «Снять все» / «Инвертировать»; безопасные
  операции предотмечены при открытии.
- Если в выборе есть ⚠-операции — перед запуском вылезет предупреждение
  с их последствиями.
- Выполнение — в фоне, вывод каждой команды идёт в «Журнал» справа:
  ошибки — кирпичным, блоки ребут-операций — янтарём, остальное —
  серым. После reset-операций статус напомнит про перезагрузку.

## 6. Файлы рядом с exe

| Файл | Назначение |
|---|---|
| `CleanSweep.ini` | настройки: включённые базы, отметки, пресет, keep-list кук |
| `CleanSweep.log` | журнал операций (деинсталляции, удаления, пропуски) |
| `Custom\*.ini` | ваши правила клинера |
| `data\*.ini` | базы клинера (Winapp2/3, Default, CCleaner, Winappx) — можно обновлять без пересборки |
| `data\leftover-signatures.json` | сигнатуры известных остатков |

Параметры командной строки: `-c` — открыть сразу клинер,
`-e` (или `-net`) — форму сброса сети, `-h` — «О программе».
F1 — «О программе» из любой формы.

## 7. Что защищено от удаления

Движок отказывается трогать (даже если отметить):

- системные каталоги и файлы Windows (`System32`, `WinSxS`, `Boot`,
  шрифты, servicing);
- защищённые ветки реестра (`HKLM\SYSTEM\...`, SAM, SECURITY, политики);
- системные службы и задачи `\Microsoft\...`;
- базовые правила фаервола и важная автозагрузка;
- junction/reparse-точки (не обходятся и не удаляются);
- папки с живым `.exe` и элементы, принадлежащие другой программе;
- cookie-базы удалением файла (только точечная чистка внутри);
- элементы с оценкой «рискованный»/«инфо» — в любых списках остатков.
